## 🚀 Cómo Usar

### Opción 1: Ver en Vivo
Visita: `https://yennelymorillo.github.io/MY-PORTFOLIO/`

### Opción 2: Ejecutar Localmente

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/YennelyMorillo/MY-PORTFOLIO.git
   cd MY-PORTFOLIO
   ```

2. **Abrir en el navegador**
   - Simplemente abre el archivo `index.html` en tu navegador preferido
   - O usa Live Server en VS Code para desarrollo

### Opción 3: Desplegar en GitHub Pages

1. **Configurar GitHub Pages**
   - Ve a Settings → Pages
   - Selecciona la rama `main` o `master`
   - Guarda y espera unos minutos

2. **Tu sitio estará disponible en:**
   ```
   https://tuusuario.github.io/MY-PORTFOLIO/
   ```

## 📝 Personalización

### 1. Información Personal

Edita `index.html` y actualiza:
- Nombre y título profesional
- Biografía y descripción
- Enlaces de redes sociales
- Servicios ofrecidos
- Testimonios

### 2. Imágenes

1. Agrega tus fotos en la carpeta `assets/images/`
2. Actualiza las referencias en el HTML:
   ```html
   <img src="assets/images/tu-foto.jpg" alt="Descripción">
   ```
3. Lee el archivo `assets/README.md` para más detalles

### 3. Colores y Estilos

Modifica las variables CSS en `styles.css`:
```css
:root {
    --primary-color: #FFB6C1;      /* Rosa principal */
    --secondary-color: #FF69B4;    /* Rosa secundario */
    --accent-color: #FFC0CB;       /* Rosa acento */
}
```

### 4. Formulario de Contacto

1. Registrarte en [Web3Forms](https://web3forms.com/)
2. Obtén tu Access Key
3. Reemplaza en `index.html`:
   ```html
   <input type="hidden" name="access_key" value="TU_ACCESS_KEY_AQUI">
   ```
